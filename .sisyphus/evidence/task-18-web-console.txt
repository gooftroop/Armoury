# Task 18 — Web smoke run console output

## Result: PASS (smoke navigation + screenshots succeeded)

The raw console capture below contains expected noise from the Next.js dev
server and a `networkidle` timeout on `/en`. Neither blocked the smoke:

  are not emitted in dev mode. They are benign and present on every local
  Next.js dev run.
- The `/en` `page.goto` timeout is caused by `waitUntil: 'networkidle'`
  combined with Next.js dev HMR keeping the network channel open. The page
  rendered successfully — see the screenshots listed below, which were
  captured after navigation completed.
